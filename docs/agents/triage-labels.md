# Triage labels

The skills speak in terms of canonical triage roles. This file maps those roles to the label strings used in the `HVN` Linear team.

## State roles

| Role | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

## Category roles

| Role | Label in our tracker | Meaning |
| --- | --- | --- |
| `bug` | `Bug` | Something is broken |
| `enhancement` | `Feature` or `Improvement` | `Feature` adds a capability; `Improvement` refines one that exists |

When a skill names a role, apply the matching label string.
